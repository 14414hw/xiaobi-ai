# PenAI 发行版

面向有道词典笔（RK3562，逻辑画布 936×280）的 AI 助手发行版源码。

本仓库只包含发行版：应用标识 `8001123456789110`，当前版本 `1.0.2`。
内部调试版及其开发资料不在本仓库内。

## 目录结构

```
src/                       应用源码（页面、数据与工具模块）
tools/build.mjs            构建入口：编译并校验 .amr
tools/check_amr.py         安装包自包含校验
tools/security_scan.py     开源安全扫描（密钥、凭据、内部资料）
tools/tests/release_test.mjs  发行版静态断言
docs/                      更新日志
package.json               发行版本元数据
package-lock.json          依赖锁定
app_icon.png               发行版图标
```

## 构建

环境要求：Node.js 18 及以上、Python 3、npm。

```
npm ci
node tools/build.mjs
```

产物为当前目录下的 `8001123456789110.1_0_2.amr`。构建脚本会先编译页面，
再逐项核对安装包清单：manifest 登记条目与包内文件一一对应（大小与 MD5）、
应用入口与全部注册页面齐全、原生模块随包、无调试页面、路径安全。
校验失败时构建以非零状态退出。

运行静态断言与安全扫描：

```
node tools/tests/release_test.mjs
python tools/security_scan.py .
```

安全扫描拒绝密钥明文、登录凭据字段、设备地址与序列号、鉴权口令、
内部调试版标识、调试版存储路径及内部资料路径进入仓库。
构建脚本会先执行该扫描，命中任一条即终止构建。

## 安装

```
adb connect <设备地址>:5555
adb push 8001123456789110.1_0_2.amr /userdisk/penai_release.amr
adb shell miniapp_cli install /userdisk/penai_release.amr
```

按设备固有行为，安装后需重启一次宿主进程，再从桌面图标启动应用。
安装包是自包含的，不需要预先推送资源文件，也不含任何原生模块。

## 配置与数据

发行版不预设 API 地址、密钥或模型。首次使用在设置页填写服务商接口地址、
密钥与模型名称，也可从接口拉取模型列表后点选。

数据写入 `/userdisk/penair`，与调试版目录隔离，两者可并存且互不读写。
核心提示词中的公式与化学结构规范在运行时合成并锁定，用户补充要求只能追加。
诊断后门在发行版中不可用。

## 项目边界

本仓库开源的是「小笔 AI」发行版，不附带任何原生模块。安装包校验会拒绝
包含 `.so` 或 `libs/` 条目的产物。云游戏相关的页面、模块、侧车脚本与
设备标识均不属于本项目，构建门禁会拦截其重新混入。
