PenAI 发行版 更新日志

版本：1.0.2
发布日期：2026年11月22日
应用标识：8001123456789110
适用设备：有道词典笔（RK3562，逻辑画布 936×280）
安装包：8001123456789110.1_0_2.amr（526654 字节）


一、本次变更

1. 安装包重构为自包含形态
   旧版 1.0.1 的构建过程只复制页面源码与图标，存在组件缺件。本次改为
   将全部所需文件随 .amr 一同打包，设备端不再需要预先推送任何辅助文件。

2. 构建期增加安装包完整性校验
   新增校验脚本 tools/check_amr.py，在每次构建结束后自动执行，检查内容包括：
   （1）manifest 中登记的条目与包内文件一一对应，逐项核对文件大小与 MD5；
   （2）应用入口、主页以及 app.json 中登记的全部页面编译产物均在包内；
   （3）不含开发调试页面；
   （4）包内路径不含越级或绝对路径。
   任一检查失败即终止构建，不再依赖安装后人工排查缺件。

3. 版本号递增
   发行版本由 1.0.1 升至 1.0.2，界面版本号与安装包版本号同源，确保设备端
   安装时正确覆盖旧版本。


二、本版本包含的功能优化

1. 结构式展示
   对话页与历史页的分子名同一行显示绿色「放大」标签，标签位于结构图上方，
   不占用额外高度。此前将提示放在图下方时，在 280 像素屏上会被输入栏遮挡。
   点击进入单分子大图页，右上提供「恢复原状」返回入口。
   结构图宽度按原子数量分级，复杂分子不再压缩到难以辨认。

2. 输入法词库
   词库由生成脚本统一产出，保留低频学科字与学科词组的保底权重，避免出现
   常用学科单字无法输入的情况。输入候选条与四行键位完整显示。

3. 结构解析与校验
   结构校验改用凯库勒化之后的真实单双键计算价态，避免杂环原子被误判；
   芳香性判断依据原子芳香标记，避免稠环体系的误报；
   分子式识别要求含数字，避免与短链结构混淆；
   高频分子名称采用精确匹配，超限或无法绘制的结构明确显示原因。

4. 公式与方程式
   分式、根号与矢量符号按统一规则渲染；方程式中的分子式不与结构式混淆；
   反例白名单覆盖常见协议、单位、日期与网址写法。

5. 页面启动方式
   通过命令行启动时，页面名不得带破折号，正确写法为 start 应用标识 页面名。
   带破折号时系统会查找不存在的页面文件，表现为整屏黑且无错误提示。
   该说明已纳入项目备忘，属于操作约定，不涉及应用代码变更。


三、发行版约定

1. 发行版不预设任何接口地址与 API 密钥，用户需在设置页自行填写。
2. 使用独立的数据存储目录。
3. 核心提示词中的公式与化学结构规范处于锁定状态，用户补充要求只能追加，
   不能覆盖或删除。
4. 模型列表可通过设置页从接口拉取并点选。


四、安装与升级说明

1. 直接安装本 .amr 文件即可，无需预先推送配置文件或其他资源。
2. 按设备固有行为，安装后需重启一次宿主进程，随后从桌面图标启动应用。
3. 应用启动后显示「小笔 AI v1.0.2」，设置页显示「发行版 v1.0.2」。
